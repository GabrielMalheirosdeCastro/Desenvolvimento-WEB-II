# Plano de Ação — v1.7.1 Hotfix da Tela de Mentoria (H5 / RF09)

**Data:** 2026-06-14
**Solicitado por:** Gabriel Malheiros de Castro
**Contexto:** A tela `/dashboard/mentoria` está **quebrada em produção** (v1.7.0). Ao navegar,
a SPA exibe `Unexpected Application Error! ImageWithFallback is not defined`
(`ReferenceError`), derrubando a rota inteira via ErrorBoundary do React Router.

## Causa-raiz

Na refatoração da v1.7.0 (item H5), o componente `MentorshipPage.tsx` passou a **usar**
`<ImageWithFallback>` (linha ~320, bloco "Candidatar-se como Mentor"), mas o **import foi
omitido**. O componente existe em `apps/web/src/app/components/figma/ImageWithFallback.tsx`
e é importado corretamente por `ConcentrationPage.tsx` (linha 1) e `LibraryPage.tsx` (linha 2).
Apenas a `MentorshipPage` ficou sem o import.

- **Por que TS/lint não pegaram:** o `get_errors` (language server) retornou "No errors" no
  arquivo durante a auditoria, mas o erro é de **referência em runtime** após o bundle. A
  validação correta seria `npm run build` (Vite/Rollup falha ou gera binding indefinido) +
  navegação real via Playwright MCP — etapa que não foi executada na v1.7.0.

## Objetivo

Restaurar a tela de Mentoria em produção adicionando o import ausente, **sem** alterar nenhum
outro comportamento, e publicar como **v1.7.1** (PATCH, correção de bug).

## Etapas

- [ ] 1. Adicionar `import { ImageWithFallback } from "../components/figma/ImageWithFallback";`
        no topo de `apps/web/src/app/pages/MentorshipPage.tsx` (junto aos demais imports).
- [ ] 2. `get_errors` no arquivo + varredura: confirmar que nenhuma outra página usa um símbolo
        sem importar (grep de `ImageWithFallback` já confirmou que só a Mentoria estava sem).
- [ ] 3. `npm run build` da SPA (gera `apps/web/dist/**` — versionado, Dockerfile copia pronto).
- [ ] 4. Validar local (porta 3010): navegar `/dashboard/mentoria` sem o ReferenceError.
- [ ] 5. Bump 1.7.0 -> 1.7.1 nos 3 `package.json` (raiz + apps/web + apps/api).
- [ ] 6. `CHANGELOG.md`: nova seção `## [1.7.1] - 2026-06-14` em `Fixed`.
- [ ] 7. Commit atômico pt-BR (`fix(mentoria): restaura import de ImageWithFallback`).
- [ ] 8. Push `master`; aguardar publicação; **um único** `node scripts/deploy.mjs` se necessário
        (evitar corrida workflow + manual — lição registrada na v1.6.0).
- [ ] 9. `curl /version == 1.7.1` + `/healthz` ok.
- [ ] 10. Validação visual Playwright MCP (estação): `/dashboard/mentoria` renderiza sem erro.

validado por navegação real na estação via Playwright MCP.
